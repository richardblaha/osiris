# Change Log

All notable changes to the `osiris-dexpi` extension are documented here.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0-alpha.1] - 2026-09-03

### Added

- Tolerant DEXPI/Proteus XML parser producing a normalized `DexpiModel`.
- Rule-based structural validator (`DEXPI001`–`DEXPI008`) wired to the Problems panel.
- Custom-editor P&ID preview with SVG rendering and click-to-select.
- `DEXPI: Export P&ID as SVG` command.
- Validate-on-save (`osiris-dexpi.validateOnSave`).
