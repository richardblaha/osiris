# Change Log

All notable changes to the `osiris-step` extension are documented here.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0-alpha.1] - 2026-09-03

### Added

- ISO 10303-21 tokenizer and parser (`HEADER` + `DATA`, forward references,
  typed parameters, complex instances).
- Wireframe / point-cloud geometry extraction (no NURBS tessellation).
- three.js 3D preview custom editor with orbit controls and fit-to-view.
- `STEP: Show File Header` and `STEP: Entity Statistics` commands.
